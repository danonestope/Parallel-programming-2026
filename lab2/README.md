# Отчёт по Лабораторной работе№2

**Цель работы:**
- Модифицировать программу умножения матриц из лабораторной работы №1 для параллельной работы по технологии OpenMP, провести серию экспериментов с разным количеством потоков, разными размерами матриц и разным количеством вычислительных ядер, а также проанализировать полученные результаты.

**Запуск программы:**
- ./matrix_app <размер_матрицы> <количество_потоков>

**Параметры эксперимента:**
- Размеры матриц: n = 200, 400, 800, 1200, 1600, 2000.
- Количество потоков: 1, 2, 4, 8, 12.
- Количество ядер: фиксированное (4)

**Выводы:**
- При малых размерах (n = 200) накладные расходы на создание потоков, синхронизацию и распределение итераций сопоставимы с полезной работой. Ускорение составляет лишь ~2.4 при 4 потоках вместо теоретических 4. С ростом n доля накладных расходов падает, и ускорение приближается к числу физических ядер.
- Время выполнения растёт как O(n3): при увеличении n в 10 раз (200 → 2000) время в один поток растёт примерно в 1000 раз (0.012 → 11.85 с), что подтверждает кубическую сложность классического алгоритма.
