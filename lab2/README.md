# Отчёт по Лабораторной работе№2

**Цель работы:**
- Модифицировать программу умножения матриц из лабораторной работы №1 для параллельной работы по технологии OpenMP, провести серию экспериментов с разным количеством потоков, разными размерами матриц и разным количеством вычислительных ядер, а также проанализировать полученные результаты.

**Запуск программы:**
- ./lab2 <размер_матрицы> <количество_потоков>

**Параметры эксперимента:**
- Размеры матриц: n = 200, 400, 800, 1200, 1600.
- Количество потоков: 1, 2, 4, 8, 12.
- Количество ядер: фиксированное (4)

**Выводы:**
- Рост времени с размером задачи: при увеличении размера матрицы (от 200 до 1600) время выполнения растет. Например, для 1 потока время выросло с 151 мл до 84973 мл. Эффективность распараллеливания: Начиная с размера 800 и выше, наблюдается явное снижение времени выполнения при увеличении количества потоков. Пример для N=1600: Время на 1 потоке — 84973 мл, а на 12 потоках — 10960 мл. Разница почти в 8 раз.
- Для N=1600 на 12 потоках ускорение — 7.75x. Масштабируемость: С увеличением размера задачи ускорение растет.
- Для 4 потоков: ускорение растет с ~3.16 (N=400) до ~3.49 (N=1600).
- Для 12 потоков: ускорение растет с ~4.58 (N=400) до ~7.75 (N=1600).
- Это подтверждает, что чем больше работы приходится на каждый поток, тем меньше относительный вес накладных расходов OpenMP и тем эффективнее параллелизм. Пик эффективности: Наибольшее ускорение достигается на максимальном размере (1600) при максимальном количестве потоков (12). Это говорит о том, что для данной задачи имеет смысл использовать максимальное доступное количество потоков только при больших объемах вычислений.
