# Лабораторная работа №3: Параллельное умножение матриц (OpenMP)

В данном проекте реализовано умножение двух случайно сгенерированных матриц с использованием технологии параллельного программирования **OpenMP**. Программа позволяет проводить серию экспериментов с различным количеством потоков.

## Особенности реализации
*   **Базис:** Взят код из Лабораторной работы №1 (чтение/запись файлов, генерация матриц).
*   **Технология:** OpenMP (директива `#pragma omp parallel for`).
*   **Оптимизация:** Используется кэш-дружественный порядок обхода циклов `k-i-j`.
*   **Эксперименты:** Программа автоматически тестирует матрицы с количеством потоков `1, 2, 4, 8, ...` (до максимально доступного в системе).
*   **Верификация:** Результат умножения на C++ автоматически проверяется через библиотеку `NumPy` в Python (скрипт `check.py`).

## Замечания и анализ результатов

- Можно заметить, что в сравнении со второй лабораторной работой даже при условии использования 1 потока, OpenMP-версия оказалась намного быстрее. 
- Причиной этому в основе является тот факт, что в этой лабораторной работе для удобства я перешел от двумерного массива `vector<vector<double>>` к одномерному массиву для хранения матриц, а также за место 4 ядер я использую 8.
- Это привело к увеличению скорости в **~2,5 раза**. (Ну или по крайней мере я так думаю...)
